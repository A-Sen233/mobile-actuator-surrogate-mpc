# Public Release Scope

## Included

The package includes code necessary to inspect or regenerate the central computational workflow:

- one-dimensional and two-dimensional PDE discretizations;
- mobile-actuator ODE dynamics and spatial source maps;
- synthetic training, validation, and test trajectory generation;
- neural surrogate architectures;
- two-dimensional physics-informed training loss;
- autoregressive surrogate evaluation;
- mobile and fixed actuator MPC implementations;
- numerical-PDE prediction modes;
- one-dimensional SVD-RBFNN baseline;
- plotting and small reference metric files;
- environment, execution, and availability documentation.

## Intentionally excluded

- trained `.pth`, `.pt`, `.pkl`, and other model artifacts;
- cached `.npz`/`.npy` trajectories and optimizer states;
- generated figures, font previews, and presentation-only assets;
- full historical output directories and logs;
- Python caches and temporary validation directories;
- `main.py`, which is a separate greedy-partition development baseline not required by the manuscript workflow;
- the two-dimensional Tucker-RBFNN comparison script and its external model artifacts.

## Selection principle

Files were selected by tracing dependencies from the two-dimensional and one-dimensional training, evaluation, and MPC entry points. The package contains source code and small reference metrics; trained models, trajectory arrays, and figures are generated by the scripts.
