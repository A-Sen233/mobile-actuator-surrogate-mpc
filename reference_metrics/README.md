# Reference Metrics

These small JSON files are snapshots from the authors' existing runs. They are included for coarse sanity checking and to document the numerical summaries used during manuscript preparation.

- `2d_mpc_comparison.json`: two-dimensional mobile/fixed closed-loop summary.
- `2d_mobile_summary.json`: two-dimensional mobile-actuator run summary.
- `2d_fixed_summary.json`: two-dimensional fixed-actuator run summary.
- `1d_mpc_comparison.json`: one-dimensional mobile/fixed/SVD-RBFNN comparison summary.
- `1d_surrogate_evaluation.json`: one-dimensional surrogate evaluation metrics.
- `1d_training_config.json`: one-dimensional surrogate configuration captured during training.
- `1d_svd_rbf_training.json`: one-dimensional SVD-RBFNN configuration and fit metrics.

Exact wall-clock and solve-time values are hardware dependent. These files do not replace regenerated result arrays or figure source data.
